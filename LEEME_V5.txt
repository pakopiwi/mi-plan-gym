MI PLAN GYM V5 - CORRECCION DE CARGA MEZCLADA

El problema observado era compatible con una mezcla de index.html nuevo y archivos CSS/JS antiguos conservados por la cache de la PWA. Por eso aparecian la estructura nueva, botones con estilo antiguo y zonas dinamicas vacias.

ESTA VERSION USA NOMBRES NUEVOS
- app-v5.js
- styles-v5.css

SUBIR A GITHUB
1. Antes de nada, conserva cualquier JSON exportado.
2. Sube a la raiz del repositorio estos cinco archivos:
   - index.html (sustituir)
   - app-v5.js (nuevo)
   - styles-v5.css (nuevo)
   - service-worker.js (sustituir)
   - LEEME_V5.txt (opcional)
3. No borres manifest.json, images ni icons.
4. app.js y styles.css antiguos pueden quedarse, pero V5 ya no los utiliza.
5. Espera a que termine GitHub Pages.
6. Abre primero la URL normal en Chrome y confirma que junto al titulo aparece v5.
7. Cierra completamente la app instalada y vuelve a abrirla.

COMPROBACIONES
- Debe verse la etiqueta v5 junto a Mi Plan Gym.
- El calendario debe mostrar el nombre del mes, cabecera D L M X J V S y 42 casillas.
- Menu debe mostrar las cinco comidas.
- Datos debe mostrar los botones con diseño gris, no botones nativos cuadrados.
- Si JavaScript falla, V5 muestra un aviso amarillo con el error en vez de dejar zonas vacias.

DATOS ANTERIORES
V5 intenta migrar automaticamente datos guardados con las claves v4 y v1. Aun asi, conserva siempre el JSON exportado.
